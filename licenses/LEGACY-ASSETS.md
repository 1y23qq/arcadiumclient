# Retained Arcadium assets

The Arcadium icon, user-supplied Inter font, optional design fonts, introduction
site and performance research notes were migrated from the retired Arcadium
Dolphin project. No Dolphin/Axolotl game code or old launcher is distributed.

Inter remains SIL Open Font License 1.1; see Inter-OFL.txt. The other files in
design/fonts retain their original rights and are not bundled with the launcher.
The Arcadium icon is the project's existing user-supplied brand asset.
