# Gradle Wrapper notices

The three public Gradle Wrapper JARs and their generated launch scripts are
covered by Apache-2.0, independently of Arcadium's GPL-3.0-only project license.
Original script copyright and license headers remain intact.

- `client-ui/gradle/wrapper/gradle-wrapper.jar` matches the official Gradle
  8.12.1 Wrapper byte for byte, SHA-256
  `2db75c40782f5e8ba1fc278a5574bab070adccb2d21ca5a6e5ed840888448046`.
- `client-runtime/gradle/wrapper/gradle-wrapper.jar` and
  `game-branding/gradle/wrapper/gradle-wrapper.jar` match the official Gradle
  9.5.1 Wrapper byte for byte, SHA-256
  `497c8c2a7e5031f6aa847f88104aa80a93532ec32ee17bdb8d1d2f67a194a9c7`.

`8.12.1/LICENSE`, `8.12.1/NOTICE`, `9.5.1/LICENSE`, and `9.5.1/NOTICE`
are unmodified original Gradle files from the exact pinned release commits.
`Apache-2.0-full.txt` additionally retains the complete official Apache 2.0
text, including its appendix. `provenance.json` records source URLs, commit
IDs, wrapper and script hashes, and the official published wrapper checksums.

The Wrapper JAR version is distinct from the Gradle distribution selected by
gradle-wrapper.properties. No byte identity is claimed for launch scripts
generated by a different Gradle version. Their retained Apache headers and
this complete license cover their own code; they are not relabeled as solely
Arcadium GPL code.

The original Gradle NOTICE describes dependencies of the complete Gradle
distribution. It is preserved without modification for attribution and does
not mean that the distribution or every component it mentions is included in
this source repository. Build-time Gradle distributions are not published here.
