# Custom F3

Enable Custom F3 in the Mods menu, then use F3 normally. The module is disabled
by default. F3 + M opens the module editor. General settings include font scale,
text shadow, background color, opening/closing animation, spacing, automatic
display and the debug graph/sidebar/bossbar options.

The editor supports both columns, repeated modules, ordering, separators,
per-module colors, per-line visibility, coordinate colors, FPS colors, memory
coloring and time formats. Data absent from an older game or unavailable from a
multiplayer server is omitted rather than invented.

Spec Spoof settings replace only the selected hardware/system strings drawn in
Custom F3. Empty fields keep the real text. These settings do not change the
graphics device, system properties, FPS counters, frame-time samples or packets.

BetterF3's native data collectors are retained for 1.21.11 and 26.2, with an
Arcadium configuration and renderer. The legacy versions use native game data
through version-specific adapters. Attribution is in `NOTICE.md`.
