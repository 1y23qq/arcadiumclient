Customize Minecraft's text shadow rendering globally.

## Features

- Hide Text Shadow
    - Removes text shadow completely. This can help boost performance.
- Force Text Shadow
    - Forces shadow on all text globally. Does nothing if Hide Text Shadow is enabled.
- Alternate Text Shadow
    - Only translates text shadow down instead of down and to the right.
