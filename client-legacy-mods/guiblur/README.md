# Legacy GUI Blur

Arcadium's Minecraft 1.7.10 port of [Blur](https://github.com/Polyfrost/Blur), based on commit `7693f7673c5975b0e3ce1e06704670bd55e17015`.

Configure **Legacy GUI Blur** in Arcadium Options. Build with `./gradlew build` or the repository's client build script.

Original authors and [MIT license](LICENSE) are retained.
