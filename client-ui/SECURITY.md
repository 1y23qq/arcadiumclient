# Security policy

Report vulnerabilities to the Arcadium maintainers through [Arcadium Discord](https://discord.gg/QbNfaCHjUz). Ask for a private conversation before sharing details. Do not publish active exploits, account cookies, session tokens or private logs in public issues or chat.

Include the Arcadium version, affected component and reproduction steps. This fork's maintainers handle Arcadium reports independently from the upstream OneConfig project.
