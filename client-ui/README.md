# Arcadium Core

Arcadium's configuration and HUD library, adapted from [OneConfig](https://github.com/Polyfrost/OneConfig) by Polyfrost and contributors. This is an independent fork, not an official Polyfrost release.

The adaptation is conveyed under GNU GPL version 3, as permitted by section 5 of the original OneConfig Additional Terms. The original [LICENSE](LICENSE), additional terms, source headers and contributor notices are retained. See [NOTICE.md](NOTICE.md) and the repository's [asset notices](../licenses/assets/README.md). Bundled fonts keep their own SIL Open Font License.

For Arcadium installation help, bugs or security reports, contact the maintainers through [Arcadium Discord](https://discord.gg/QbNfaCHjUz). Please ask for a private channel before sharing security details or account information.

Upstream API documentation remains at [docsv1.polyfrost.org](https://docsv1.polyfrost.org), with an [example mod](https://github.com/Polyfrost/OneConfigExampleMod/). Those resources describe upstream OneConfig and may differ from this fork. Upstream authors are credited in the source and notices; their names and marks do not imply endorsement of Arcadium.

Arcadium GUI defaults use Inter. The optional pixel-style UI fallback uses Monocraft. Minecraft's own game/HUD font and resource-pack font options continue to use the native game renderer.

Original technical references: [OneConfig Bootstrap](https://github.com/Polyfrost/OneConfig-Bootstrap), [upstream license](https://github.com/Polyfrost/OneConfig/blob/master/LICENSE), [library Maven metadata](https://repo.polyfrost.org/api/badge/latest/snapshots/org/polyfrost/oneconfig/1.8.9-forge?color=1452cc&name=OneConfig), and [loader Maven metadata](https://repo.polyfrost.org/api/badge/latest/snapshots/org/polyfrost/oneconfig/stage0?color=1452cc&name=Loader%20(for%20Legacy%20Forge)).
