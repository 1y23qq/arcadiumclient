The launcher

From install to in-game.

Arcadium installs the game, Java and client components for you. Sign in once, finish setup and launch Minecraft from the native app.

  1. 1
    Install Arcadium

    Run the Windows installer, or open the macOS disk image and move Arcadium to Applications. Choose where to keep your game files during setup.

  2. 2
    Sign in with Microsoft

    Your browser opens automatically. Use the account that owns Minecraft Java Edition.

  3. 3
    Launch Minecraft

    The launcher downloads the required files and prepares the Minecraft version you choose.

Microsoft account sign-in

Authentication happens in your browser. Saved credentials use Windows DPAPI or macOS Keychain.

Discord Rich Presence

Show Arcadium, your Minecraft version and elapsed play time in Discord. You can turn this on or off in launcher settings.

Your game files

Choose the installation folder during setup. Your accounts, settings and game data stay on your computer.

Before you install

A few common questions.

Need help with something else?
Join our Discord ↗

Do I need to own Minecraft?

Yes. You need an account that owns Minecraft Java Edition. Sign in through the Microsoft page opened by the launcher. Arcadium never asks for your Microsoft password.

Do I need to install Java myself?

No. The launcher downloads the Java runtime and game components required for the client. An Internet connection is needed during setup.

Can I add other mods?

Forge 1.8.9 mods are supported when playing Minecraft 1.8.9. Put mod JARs in your Arcadium game directory's mods folder and install any libraries required by the mod's author. No separate Forge installation is needed. Compatible Ornithe Gen2 mods also work. Forge mods are not supported on the 1.7.10 installation. OptiFine and other performance mods are blocked.

Is there a macOS or Linux version?

Intel Macs require macOS 12 or later. Apple Silicon Macs require macOS 13 or later. Choose the matching download on the download page. Linux support is planned.

Why does macOS block the first launch?

The current Mac build is not notarized by Apple. After trying to open Arcadium, choose Open Anyway for Arcadium Client. On macOS 12, open System Preferences > Security & Privacy > General. On macOS 13 or later, open System Settings > Privacy & Security. Follow Apple's instructions if prompted.

Where should I report a bug?

Report it in Discord. Include the Arcadium version, what happened and the steps needed to reproduce it. Remove account tokens and personal information from logs before sharing them.
