Client

Configure the client from Arcadium Options, on the main menu or in game.

  • HUD editor

    Move and resize HUD modules, then adjust their text, colours and layout one by one.

  • Modules and keybinds

    Switch modules on or off, change their settings, bind keys and save setups as profiles.

  • Themes

    Choose a theme and customise the main menu, including its background.

  • Resource packs

    Sort and organise your resource packs.

  • Launcher

    Installs Java and the client components for the version you choose, with Microsoft account sign-in.

Help

Answers to common setup questions. For anything else, ask in our Discord.

Get help on Discord
Do I need to install Java?

No. The launcher downloads the Java runtime and components needed for your selected version. An internet connection is needed during setup.

Which Minecraft versions can I play?

Arcadium supports Minecraft Java Edition 1.7.10, 1.8.9, 1.21.11 and 26.2. Choose a version in the launcher. Available modules differ between versions.

Can I add other mods?

Yes. Use Forge mods on 1.7.10. On 1.8.9, Arcadium supports Forge 1.8.9 mods and compatible Ornithe Gen2 mods. On 1.21.11 and 26.2, use Fabric mods made for that version. Add required libraries too. OptiFine and duplicate performance mods are blocked on 1.8.9.

How do I open Arcadium on a Mac?

Download the version for your Mac's processor, open the DMG and drag Arcadium Client into Applications. The current Mac builds are not notarized. If macOS blocks the first launch, follow Apple's instructions for opening the app.

Where can I report a problem?

Join our Discord and include your Arcadium version and steps to reproduce the issue. Remove account tokens and personal information before sharing a log.
